# 服务启动验证指南

## 快速验证命令

### 1. 测试接口验证（推荐）

**生产环境（端口 8081）：**
```bash
# 简单测试接口
curl http://localhost:8081/api/test/hello

# 预期响应：
# Hello World!
```

**测试环境（端口 8082）：**
```bash
# 简单测试接口
curl http://localhost:8082/api/test/hello

# 预期响应：
# Hello World!
```

### 2. Spring Boot Actuator 健康检查

**生产环境：**
```bash
curl http://localhost:8081/actuator/health

# 预期响应（JSON格式）：
# {"status":"UP"}
```

**测试环境：**
```bash
curl http://localhost:8082/actuator/health

# 预期响应（JSON格式）：
# {"status":"UP"}
```

### 3. 格式化输出（更易读）

**生产环境：**
```bash
# 使用 jq 格式化 JSON（如果已安装）
curl -s http://localhost:8081/actuator/health | jq .

# 或使用 python 格式化
curl -s http://localhost:8081/actuator/health | python3 -m json.tool
```

**测试环境：**
```bash
curl -s http://localhost:8082/actuator/health | python3 -m json.tool
```

## 完整验证脚本

### 一键验证脚本

```bash
#!/bin/bash

echo "=========================================="
echo "服务启动验证"
echo "=========================================="
echo ""

# 检查生产环境
echo "1. 检查生产环境（端口 8081）..."
echo "   - 测试接口："
if curl -f -s http://localhost:8081/api/test/hello > /dev/null 2>&1; then
    echo "   ✅ 测试接口正常: $(curl -s http://localhost:8081/api/test/hello)"
else
    echo "   ❌ 测试接口不可用"
fi

echo "   - 健康检查："
if curl -f -s http://localhost:8081/actuator/health > /dev/null 2>&1; then
    echo "   ✅ 健康检查通过"
    curl -s http://localhost:8081/actuator/health | python3 -m json.tool 2>/dev/null || curl -s http://localhost:8081/actuator/health
else
    echo "   ❌ 健康检查失败"
fi

echo ""
echo "2. 检查测试环境（端口 8082）..."
echo "   - 测试接口："
if curl -f -s http://localhost:8082/api/test/hello > /dev/null 2>&1; then
    echo "   ✅ 测试接口正常: $(curl -s http://localhost:8082/api/test/hello)"
else
    echo "   ❌ 测试接口不可用"
fi

echo "   - 健康检查："
if curl -f -s http://localhost:8082/actuator/health > /dev/null 2>&1; then
    echo "   ✅ 健康检查通过"
    curl -s http://localhost:8082/actuator/health | python3 -m json.tool 2>/dev/null || curl -s http://localhost:8082/actuator/health
else
    echo "   ❌ 健康检查失败"
fi

echo ""
echo "3. 检查端口监听状态..."
echo "   - 生产环境端口 8081："
if netstat -tln | grep -q ":8081 "; then
    echo "   ✅ 端口 8081 正在监听"
else
    echo "   ❌ 端口 8081 未监听"
fi

echo "   - 测试环境端口 8082："
if netstat -tln | grep -q ":8082 "; then
    echo "   ✅ 端口 8082 正在监听"
else
    echo "   ❌ 端口 8082 未监听"
fi

echo ""
echo "4. 检查进程状态..."
if [ -f /opt/yaohufox/production/app.pid ]; then
    PID=$(cat /opt/yaohufox/production/app.pid)
    if ps -p $PID > /dev/null 2>&1; then
        echo "   ✅ 生产环境进程运行中 (PID: $PID)"
    else
        echo "   ❌ 生产环境进程不存在 (PID: $PID)"
    fi
else
    echo "   ⚠️  生产环境 PID 文件不存在"
fi

if [ -f /opt/yaohufox/testing/app.pid ]; then
    PID=$(cat /opt/yaohufox/testing/app.pid)
    if ps -p $PID > /dev/null 2>&1; then
        echo "   ✅ 测试环境进程运行中 (PID: $PID)"
    else
        echo "   ❌ 测试环境进程不存在 (PID: $PID)"
    fi
else
    echo "   ⚠️  测试环境 PID 文件不存在"
fi

echo ""
echo "=========================================="
```

### 保存为脚本文件

```bash
# 保存脚本
cat > /opt/yaohufox/scripts/verify-service.sh << 'EOF'
# 上面的脚本内容
EOF

# 添加执行权限
chmod +x /opt/yaohufox/scripts/verify-service.sh

# 执行验证
/opt/yaohufox/scripts/verify-service.sh
```

## 验证接口说明

### 1. `/api/test/hello` - 测试接口

- **方法**: `GET`
- **路径**: `/api/test/hello`
- **描述**: 简单的健康检查接口，返回 "Hello World!"
- **响应**: `200 OK`
- **响应体**: `Hello World!`

**优点**:
- 简单直接，不需要解析 JSON
- 响应快速
- 不依赖 Actuator 模块

### 2. `/actuator/health` - Actuator 健康检查

- **方法**: `GET`
- **路径**: `/actuator/health`
- **描述**: Spring Boot Actuator 提供的健康检查接口
- **响应**: `200 OK`
- **响应体**: `{"status":"UP"}` 或 `{"status":"DOWN"}`

**优点**:
- 标准的 Spring Boot 健康检查接口
- 可以检查数据库连接等组件状态
- 返回详细的健康信息（如果配置了 `show-details`）

## 常见验证场景

### 场景 1: 快速验证服务是否启动

```bash
# 最简单的方式
curl http://localhost:8081/api/test/hello
```

### 场景 2: 验证服务健康状态

```bash
# 检查健康状态
curl -s http://localhost:8081/actuator/health | grep -q '"status":"UP"' && echo "服务正常" || echo "服务异常"
```

### 场景 3: 在 Jenkins 中验证

```bash
# 在 Jenkins Pipeline 中使用
if curl -f -s http://localhost:8081/api/test/hello > /dev/null 2>&1; then
    echo "✅ 服务启动成功"
else
    echo "❌ 服务启动失败"
    exit 1
fi
```

### 场景 4: 通过域名验证（如果配置了 Nginx）

```bash
# 生产环境域名
curl https://yaohufox.com/api/test/hello

# 测试环境域名
curl https://test.yaohufox.com/api/test/hello
```

## 故障排查

### 如果接口返回 404

1. **检查服务是否启动**
   ```bash
   ps aux | grep java | grep app.jar
   ```

2. **检查端口是否监听**
   ```bash
   netstat -tln | grep -E "8081|8082"
   ```

3. **检查应用日志**
   ```bash
   tail -50 /opt/yaohufox/production/app.log
   ```

### 如果接口返回 500

1. **查看详细错误日志**
   ```bash
   tail -100 /opt/yaohufox/production/app.log | grep -i error
   ```

2. **检查数据库连接**
   ```bash
   # 在日志中查找数据库相关错误
   tail -100 /opt/yaohufox/production/app.log | grep -i "database\|datasource\|postgres"
   ```

### 如果接口超时

1. **检查防火墙**
   ```bash
   sudo ufw status
   ```

2. **检查服务是否卡住**
   ```bash
   # 查看进程状态
   ps aux | grep java
   ```

## 自动化验证

### 添加到 Jenkins Pipeline

在 Jenkinsfile 的部署验证阶段，已经包含了健康检查：

```groovy
// 健康检查
if curl -f -s http://localhost:${PRODUCTION_PORT}/actuator/health > /dev/null 2>&1; then
    echo "✅ 健康检查通过"
elif curl -f -s http://localhost:${PRODUCTION_PORT}/api/test/hello > /dev/null 2>&1; then
    echo "✅ 测试接口可用"
else
    echo "❌ 服务未响应"
    exit 1
fi
```

### 定时监控脚本

```bash
#!/bin/bash
# 保存为 /opt/yaohufox/scripts/monitor-service.sh

while true; do
    if ! curl -f -s http://localhost:8081/api/test/hello > /dev/null 2>&1; then
        echo "$(date): 服务异常，发送告警..."
        # 这里可以添加告警逻辑，如发送邮件、短信等
    fi
    sleep 60  # 每60秒检查一次
done
```
