## 首次部署步骤

### 1. 在服务器上创建目录结构
```bash
cd /opt
sudo mkdir -p yaohufox/{config,certificates,data,logs,scripts,production,testing}
sudo mkdir -p yaohufox/config/{nginx,jenkins}
sudo mkdir -p yaohufox/config/nginx/{sites-available,sites-enabled}
sudo mkdir -p yaohufox/certificates/{prod,test,jenkins}
sudo mkdir -p yaohufox/data/{postgres-prod,postgres-test,jenkins}
sudo mkdir -p yaohufox/logs/{nginx,postgres,app}
```

### 2. 创建环境变量文件
按照《服务器环境搭建指南》第三节创建 `.env` 文件。

### 3. 启动数据库和应用
```bash
# 生产环境
cd /opt/yaohufox/production
docker-compose --env-file .env up -d

# 测试环境
cd /opt/yaohufox/testing
docker-compose --env-file .env up -d
```

### 4. 配置 Nginx
按照《服务器环境搭建指南》第四节创建和启用 Nginx 配置。

### 5. 在 Jenkins 中触发构建
- 登录 Jenkins：`https://Jenkins.yaohufox.com`
- 找到 `mahjong-scoreboard-deploy` 任务
- 点击「立即构建」

## 常见问题排查

### 问题 1：容器无法启动
```bash
# 查看容器日志
docker logs yaohufox-app-prod

# 检查端口占用
netstat -tlnp | grep 8081
```

### 问题 2：数据库连接失败
```bash
# 检查数据库容器
docker ps | grep postgres

# 测试连接
docker exec -it yaohufox-postgres-prod psql -U mahjong_user -d mahjong_score_system
```

### 问题 3：Nginx 502 错误
```bash
# 查看 Nginx 错误日志
sudo tail -f /opt/yaohufox/logs/nginx/production-error.log

# 检查应用是否运行
docker ps | grep yaohufox-app
```

### 问题 4：Jenkins 构建失败
- 检查 Jenkins 构建日志
- 确认 Docker 服务正在运行：`sudo systemctl status docker`
- 确认 Jenkins 用户有 Docker 权限
- 确认路径正确：`/opt/yaohufox/production` 和 `/opt/yaohufox/testing`
