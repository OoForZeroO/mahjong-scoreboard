# 数据库密码认证失败修复指南

## 问题症状

```
FATAL: password authentication failed for user "yaohu"
```

## 原因分析

应用启动时无法连接到数据库，因为：
1. 环境变量没有被正确传递给 Java 应用
2. `.env` 文件中的密码不正确
3. 数据库用户 `yaohu` 的密码在数据库中不是 `cch815566`

## 修复步骤

### 步骤 1: 验证数据库密码

在服务器上执行：

```bash
# 尝试使用密码连接数据库
psql -U yaohu -d mahjong_scoreboard_system -h localhost

# 如果连接失败，说明密码不正确
# 如果连接成功，说明密码正确，问题在于应用配置
```

### 步骤 2: 检查并修复 .env 文件

```bash
# 检查生产环境 .env 文件
cat /opt/yaohufox/production/.env

# 应该包含以下内容：
# POSTGRES_PASSWORD=cch815566
# SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system
# SPRING_DATASOURCE_USERNAME=yaohu
# SPRING_DATASOURCE_PASSWORD=cch815566
```

**如果 .env 文件不存在或内容不正确，创建/修复它：**

```bash
# 生产环境
cd /opt/yaohufox/production
sudo tee .env > /dev/null <<EOF
POSTGRES_PASSWORD=cch815566
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system
SPRING_DATASOURCE_USERNAME=yaohu
SPRING_DATASOURCE_PASSWORD=cch815566
WECHAT_APPID=你的小程序AppID
WECHAT_APPSECRET=你的小程序AppSecret
EOF

# 设置正确的权限
sudo chmod 600 .env
sudo chown jenkins:jenkins .env
```

**测试环境：**

```bash
cd /opt/yaohufox/testing
sudo tee .env > /dev/null <<EOF
POSTGRES_PASSWORD=cch815566
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test
SPRING_DATASOURCE_USERNAME=yaohu
SPRING_DATASOURCE_PASSWORD=cch815566
WECHAT_APPID=你的测试环境小程序AppID
WECHAT_APPSECRET=你的测试环境小程序AppSecret
EOF

sudo chmod 600 .env
sudo chown jenkins:jenkins .env
```

### 步骤 3: 如果数据库密码确实不正确，重置密码

```bash
# 以 postgres 用户连接
sudo -u postgres psql

# 在 psql 中执行：
ALTER USER yaohu WITH PASSWORD 'cch815566';

# 退出
\q
```

### 步骤 4: 验证修复

```bash
# 1. 验证 .env 文件内容
cat /opt/yaohufox/production/.env

# 2. 验证数据库连接
psql -U yaohu -d mahjong_scoreboard_system -h localhost -c "SELECT 1;"

# 3. 手动测试应用启动（使用环境变量）
cd /opt/yaohufox/production
source .env
java -jar \
  -Dspring.profiles.active=production \
  -Dserver.port=8081 \
  -Dspring.datasource.url="${SPRING_DATASOURCE_URL}" \
  -Dspring.datasource.username="${SPRING_DATASOURCE_USERNAME}" \
  -Dspring.datasource.password="${SPRING_DATASOURCE_PASSWORD}" \
  app.jar

# 如果启动成功，按 Ctrl+C 停止，然后通过 Jenkins 重新部署
```

### 步骤 5: 重新部署

修复后，在 Jenkins 中重新构建项目。Jenkinsfile 已经更新，会通过 `-D` 参数显式传递数据库配置。

## 已修复的问题

Jenkinsfile 已更新，现在会：
1. 通过 `-D` 参数显式传递数据库配置给 Java 应用
2. 使用 `env` 命令确保环境变量被正确传递
3. 在日志中显示数据库配置信息（密码只显示前2个字符）

## 验证部署

部署完成后，检查应用日志：

```bash
# 查看应用启动日志
tail -50 /opt/yaohufox/production/app.log

# 应该看到：
# - 数据库连接成功
# - 应用启动成功
# - 没有密码认证错误
```

## 常见问题

### Q: 为什么环境变量没有被传递？

A: 之前的 `nohup java -jar` 命令没有显式传递环境变量。现在已经修复，使用 `-D` 参数显式传递。

### Q: 如何确认密码是否正确？

A: 使用 `psql` 命令直接连接数据库：
```bash
psql -U yaohu -d mahjong_scoreboard_system -h localhost
```

### Q: 如果忘记数据库密码怎么办？

A: 可以重置密码：
```bash
sudo -u postgres psql -c "ALTER USER yaohu WITH PASSWORD '新密码';"
```

然后更新 `.env` 文件中的密码。

## 总结

1. ✅ 检查 `.env` 文件是否存在且内容正确
2. ✅ 验证数据库密码是否正确
3. ✅ 如果密码不正确，重置数据库密码
4. ✅ 提交修复后的 Jenkinsfile
5. ✅ 在 Jenkins 中重新构建

修复后，应用应该能够正常连接到数据库并启动。
