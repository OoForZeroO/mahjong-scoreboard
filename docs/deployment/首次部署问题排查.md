# 首次部署问题排查

## 问题：应用镜像不存在

### 错误现象
```
✗ mahjong-app-prod Error
Get "https://registry-1.docker.io/v2/": net/http: request canceled
Error response from daemon: Get "https://registry-1.docker.io/v2/": net/http: request canceled while waiting for connection (Client.Timeout exceeded while awaiting headers)
```

### 原因分析
1. **应用镜像尚未构建**：`mahjong-scoreboard:latest` 镜像需要通过 Jenkins 构建，首次部署时还不存在
2. **Docker Compose 版本警告**：新版本 Docker Compose 不再需要 `version` 字段

### 解决方案

#### 方案一：分步启动（推荐）

**第一步：只启动数据库**

修改 `/opt/yaohufox/production/docker-compose.yml`，暂时注释掉应用服务：

```yaml
# version: '3.8'  # 移除这行，新版本不需要

services:
  postgresql-prod:
    image: postgres:15-alpine
    container_name: yaohufox-postgres-prod
    restart: always
    environment:
      POSTGRES_DB: mahjong_score_system
      POSTGRES_USER: mahjong_user
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
      PGDATA: /var/lib/postgresql/data/pgdata
    ports:
      - "127.0.0.1:5432:5432"
    volumes:
      - /opt/yaohufox/data/postgres-prod:/var/lib/postgresql/data
      - /opt/yaohufox/config/postgres-init-prod.sql:/docker-entrypoint-initdb.d/init.sql
    networks:
      - yaohufox-network-prod
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U mahjong_user -d mahjong_score_system"]
      interval: 10s
      timeout: 5s
      retries: 5
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"

  # 暂时注释掉应用服务，等 Jenkins 构建好镜像后再取消注释
  # mahjong-app-prod:
  #   image: mahjong-scoreboard:latest
  #   ...

networks:
  yaohufox-network-prod:
    driver: bridge
```

然后启动数据库：
```bash
cd /opt/yaohufox/production
docker-compose --env-file .env up -d postgresql-prod
```

**第二步：通过 Jenkins 构建应用镜像**

1. 在 Jenkins 中触发构建
2. 等待构建完成

**第三步：取消注释应用服务并启动**

1. 取消注释 `mahjong-app-prod` 服务
2. 启动应用：
```bash
docker-compose --env-file .env up -d
```

#### 方案二：使用独立的数据库配置文件

创建 `/opt/yaohufox/production/docker-compose-db.yml`（只包含数据库）：

```yaml
services:
  postgresql-prod:
    image: postgres:15-alpine
    container_name: yaohufox-postgres-prod
    restart: always
    environment:
      POSTGRES_DB: mahjong_score_system
      POSTGRES_USER: mahjong_user
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
      PGDATA: /var/lib/postgresql/data/pgdata
    ports:
      - "127.0.0.1:5432:5432"
    volumes:
      - /opt/yaohufox/data/postgres-prod:/var/lib/postgresql/data
      - /opt/yaohufox/config/postgres-init-prod.sql:/docker-entrypoint-initdb.d/init.sql
    networks:
      - yaohufox-network-prod
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U mahjong_user -d mahjong_score_system"]
      interval: 10s
      timeout: 5s
      retries: 5

networks:
  yaohufox-network-prod:
    driver: bridge
```

启动数据库：
```bash
cd /opt/yaohufox/production
docker-compose -f docker-compose-db.yml --env-file .env up -d
```

## 修复 Docker Compose 版本警告

### 问题
```
WARN [0000] the attribute `version` is obsolete, it will be ignored
```

### 解决方案
**移除 `version` 字段**：新版本的 Docker Compose 不再需要 `version` 字段，直接删除即可。

修改前：
```yaml
version: '3.8'

services:
  ...
```

修改后：
```yaml
services:
  ...
```

## 完整修复步骤

### 1. 修复生产环境配置

编辑 `/opt/yaohufox/production/docker-compose.yml`：

```bash
cd /opt/yaohufox/production
vi docker-compose.yml
```

**修改内容：**
1. 删除第一行的 `version: '3.8'`
2. 暂时注释掉 `mahjong-app-prod` 服务（整个服务块）

### 2. 启动数据库

```bash
cd /opt/yaohufox/production
docker-compose --env-file .env up -d postgresql-prod
```

**验证数据库启动：**
```bash
# 查看容器状态
docker ps | grep yaohufox-postgres-prod

# 测试数据库连接
docker exec -it yaohufox-postgres-prod psql -U mahjong_user -d mahjong_score_system
```

### 3. 在 Jenkins 中构建应用镜像

1. 登录 Jenkins：`https://Jenkins.yaohufox.com`
2. 找到 `mahjong-scoreboard-deploy` 任务
3. 点击「立即构建」
4. 等待构建完成

### 4. 验证镜像已构建

```bash
# 查看本地镜像
docker images | grep mahjong-scoreboard

# 应该看到类似：
# mahjong-scoreboard  latest  xxx  xxx  xxx
```

### 5. 启动应用服务

编辑 `/opt/yaohufox/production/docker-compose.yml`，取消注释 `mahjong-app-prod` 服务，然后：

```bash
cd /opt/yaohufox/production
docker-compose --env-file .env up -d
```

### 6. 验证完整服务

```bash
# 查看所有容器
docker-compose ps

# 查看应用日志
docker-compose logs -f mahjong-app-prod

# 测试健康检查
curl http://localhost:8081/actuator/health
```

## 测试环境同样处理

对测试环境执行相同的步骤：

```bash
# 1. 修复 docker-compose.yml（删除 version，暂时注释应用服务）
cd /opt/yaohufox/testing
vi docker-compose.yml

# 2. 启动数据库
docker-compose --env-file .env up -d postgresql-test

# 3. 等待 Jenkins 构建测试镜像（使用 develop 或 test 分支）

# 4. 取消注释应用服务并启动
docker-compose --env-file .env up -d
```

## 快速修复脚本

创建 `/opt/yaohufox/scripts/fix-docker-compose.sh`：

```bash
#!/bin/bash

echo "修复 Docker Compose 配置文件..."

# 修复生产环境
if [ -f "/opt/yaohufox/production/docker-compose.yml" ]; then
    # 删除 version 行
    sed -i '/^version:/d' /opt/yaohufox/production/docker-compose.yml
    echo "✓ 已修复生产环境配置"
fi

# 修复测试环境
if [ -f "/opt/yaohufox/testing/docker-compose.yml" ]; then
    # 删除 version 行
    sed -i '/^version:/d' /opt/yaohufox/testing/docker-compose.yml
    echo "✓ 已修复测试环境配置"
fi

echo "修复完成！"
```

**使用方法：**
```bash
chmod +x /opt/yaohufox/scripts/fix-docker-compose.sh
/opt/yaohufox/scripts/fix-docker-compose.sh
```

---

**提示：** 首次部署时，建议先启动数据库，等 Jenkins 构建好镜像后再启动应用服务，避免镜像不存在的错误。
