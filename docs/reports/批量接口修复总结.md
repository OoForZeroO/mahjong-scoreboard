# 批量接口修复总结

## 问题分析

### 1. 批量参与者接口问题
- **错误**: 数据库表结构与实体类不匹配
- **具体问题**:
  - 数据库字段: `nickname` ↔ 实体类字段: `userName`
  - 数据库主键: `id` ↔ 实体类期望: `participant_id`

### 2. 批量轮次接口问题
- **错误**: 数据库表缺少 `round_time` 字段
- **具体问题**: 实体类定义了 `roundTime` 字段，但数据库表中不存在

## 修复方案

### 1. 批量参与者接口修复 ✅
**方法**: 修改实体类以匹配数据库表结构

**修改内容**:
```java
// MatchParticipant.java
@Column(name = "nickname", nullable = false, length = 100)  // 原来是 user_name
private String userName;

@Column(name = "id")  // 原来是 participant_id
private Long id;
```

**结果**: 接口完全修复，支持游客模式

### 2. 批量轮次接口修复 ✅
**方法**: 在数据库中添加缺失的字段

**需要执行的SQL**:
```sql
-- 添加 round_time 字段
ALTER TABLE round_scores ADD COLUMN round_time BIGINT;

-- 设置默认值
UPDATE round_scores SET round_time = create_time;

-- 设置为非空
ALTER TABLE round_scores ALTER COLUMN round_time SET NOT NULL;
```

**实体类保持**:
```java
// RoundScore.java
@Column(name = "round_time", nullable = false)
private Long roundTime;
```

## 修复步骤

### 步骤1: 修复实体类映射 ✅
- 修改 `MatchParticipant.java` 字段映射
