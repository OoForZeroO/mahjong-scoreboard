# 修复微信配置环境变量问题

## 问题描述

启动失败，错误信息：
```
Could not resolve placeholder 'WECHAT_APPID' in value "WECHAT_APPID_TEST: ${WECHAT_APPID}"
```

**原因**：微信配置的环境变量 `WECHAT_APPID` 未设置。

## 解决方案

### 方案1：在启动命令中添加环境变量（推荐）

```bash
cd /opt/yaohufox/testing

# 停止旧进程
if [ -f app.pid ]; then
    kill $(cat app.pid) 2>/dev/null
    rm -f app.pid
fi

# 启动服务（添加微信配置环境变量）
nohup java -jar \
  -Dspring.profiles.active=testing \
  -Dserver.port=8082 \
  -Dserver.address=0.0.0.0 \
  -Dspring.datasource.url=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test \
  -Dspring.datasource.username=yaohu \
  -Dspring.datasource.password=cch815566 \
  -Dwechat.appId=wx1b74f5d3678d4091 \
  -Dwechat.appSecret=da88e542e7914defac0c81ba7a6088a9 \
  app.jar > app.log 2>&1 &

echo $! > app.pid
echo "PID: $(cat app.pid)"

# 等待启动
sleep 15

# 验证
ps aux | grep java | grep 8082
curl http://localhost:8082/api/test/hello
```

### 方案2：创建 .env 文件

```bash
cd /opt/yaohufox/testing

# 创建或编辑 .env 文件
cat > .env << 'EOF'
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test
SPRING_DATASOURCE_USERNAME=yaohu
SPRING_DATASOURCE_PASSWORD=cch815566
WECHAT_APPID=wx1b74f5d3678d4091
WECHAT_APPSECRET=da88e542e7914defac0c81ba7a6088a9
EOF

# 然后启动服务（Jenkinsfile 会自动加载 .env 文件）
```

### 方案3：修改配置文件使用默认值

如果不想设置环境变量，可以修改配置文件使用默认值：

**修改 `application-testing.yml`**：
```yaml
wechat:
  appId: ${WECHAT_APPID_TEST:${WECHAT_APPID:wx1b74f5d3678d4091}}
  appSecret: ${WECHAT_APPSECRET_TEST:${WECHAT_APPSECRET:da88e542e7914defac0c81ba7a6088a9}}
```
