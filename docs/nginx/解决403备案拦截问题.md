# 解决 403 备案拦截问题

## 问题描述

Postman 调用返回 **403 Forbidden**，响应内容是阿里云 ICP 备案拦截页面。

**错误信息**：
- 状态码：403 Forbidden
- 响应内容：阿里云备案拦截页面（Non-compliance ICP Filing）

## 问题原因

1. **域名未备案**：`test.yaohufox.com` 子域名可能未备案
2. **使用 HTTP 协议**：某些云服务商要求使用 HTTPS
3. **云服务商安全策略**：阿里云可能拦截未备案的 HTTP 请求

## 解决方案

### 方案1：使用 IP 地址 + 端口（临时方案，立即可用）

**修改 Postman 环境变量**：

1. 在 Postman 中选择"测试环境"
2. 编辑 `base_url`：
   ```
   http://服务器IP:8082
   ```
   例如：`http://47.xxx.xxx.xxx:8082`

**优点**：
- ✅ 立即可用，绕过备案检查
- ✅ 不需要配置 DNS 和备案

**缺点**：
- ⚠️ 使用 IP 地址不够规范
- ⚠️ IP 地址可能变化

### 方案2：使用生产域名 + 端口（推荐）

**修改 Postman 环境变量**：

```
http://yaohufox.com:8082
```

**前提条件**：
- `yaohufox.com` 已备案
- 防火墙开放 8082 端口
- 云服务商安全组允许 8082 端口

### 方案3：配置 Nginx 反向代理 + HTTPS（长期方案）

如果 `yaohufox.com` 已备案，可以配置 Nginx 反向代理：

1. **配置 Nginx**：
   ```nginx
   server {
       listen 80;
       server_name test.yaohufox.com;
       
       location / {
           proxy_pass http://localhost:8082;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       }
   }
   ```

2. **配置 SSL 证书**：
   ```bash
   sudo certbot --nginx -d test.yaohufox.com
   ```

3. **Postman 使用 HTTPS**：
   ```
   https://test.yaohufox.com
   ```

### 方案4：备案 test.yaohufox.com 子域名

如果必须使用 `test.yaohufox.com`：

1. 在阿里云备案管理中添加子域名备案
2. 等待备案审核通过（通常需要几天到几周）
3. 配置 SSL 证书
4. 使用 HTTPS 访问

## 立即解决方案（推荐）

### 步骤1：获取服务器 IP

在服务器上执行：
```bash
curl ifconfig.me
# 或
curl ipinfo.io/ip
```

### 步骤2：修改 Postman 配置

**方法1：使用 IP 地址**
```
base_url: http://服务器IP:8082
```

**方法2：使用生产域名**
```
base_url: http://yaohufox.com:8082
```

### 步骤3：确保防火墙开放端口

```bash
# Ubuntu/Debian
sudo ufw allow 8082/tcp
sudo ufw reload

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=8082/tcp
sudo firewall-cmd --reload

# 云服务商安全组（重要！）
# 在阿里云控制台配置安全组规则：
# - 入方向规则
# - 端口：8082
# - 协议：TCP
# - 源：0.0.0.0/0
```

### 步骤4：验证访问

```bash
# 在服务器上测试
curl http://localhost:8082/api/test/hello

# 从外部测试（使用 IP）
curl http://服务器IP:8082/api/test/hello

# 或使用生产域名
curl http://yaohufox.com:8082/api/test/hello
```

## 常见问题

### Q1: 为什么使用域名会返回 403？

**原因**：
- 阿里云会检查域名的备案状态
- 未备案的域名访问 HTTP 会被拦截
- 子域名 `test.yaohufox.com` 可能需要单独备案

**解决**：
- 使用 IP 地址访问（绕过备案检查）
- 或使用已备案的主域名 `yaohufox.com`

### Q2: 使用 IP 地址是否安全？

**说明**：
- IP 地址访问是安全的，只是不够规范
- 建议作为临时方案
- 长期应该配置域名和 SSL

### Q3: 如何避免备案拦截？

**方法**：
1. 使用已备案的域名（如 `yaohufox.com`）
2. 配置 HTTPS（某些情况下可以绕过 HTTP 拦截）
3. 使用 IP 地址（临时方案）

3. **检查响应状态码**（应该是 200，不是 403）
4. **验证响应内容**（应该返回 "Hello World!" 而不是备案拦截页面）

## 注意事项

1. **云服务商安全组**：确保在阿里云控制台配置了安全组规则，允许 8082 端口
2. **防火墙**：确保服务器防火墙开放了 8082 端口
3. **服务运行**：确保测试环境服务正常运行在 8082 端口
