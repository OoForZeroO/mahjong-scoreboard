# 数据库端口配置统一说明

## 配置状态

✅ **已统一**：测试环境和生产环境都使用 PostgreSQL 默认端口 **5432**

## 当前配置

### 生产环境

**配置文件**：`mahjong-scoreboard-start/src/main/resources/application-production.yml`

```yaml
spring:
  datasource:
    url: ${SPRING_DATASOURCE_URL:jdbc:postgresql://localhost:5432/mahjong_scoreboard_system}
```

**数据库**：
- 主机：`localhost`
- 端口：`5432` ✅
- 数据库名：`mahjong_scoreboard_system`
- 用户名：`yaohu`

### 测试环境

**配置文件**：`mahjong-scoreboard-start/src/main/resources/application-testing.yml`

```yaml
spring:
  datasource:
    url: ${SPRING_DATASOURCE_URL:jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test}
```

**数据库**：
- 主机：`localhost`
- 端口：`5432` ✅
- 数据库名：`mahjong_scoreboard_system_test`
- 用户名：`yaohu`

### Jenkinsfile 配置

**测试环境部署**：
```groovy
export SPRING_DATASOURCE_URL=${SPRING_DATASOURCE_URL:-jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test}
```

**生产环境部署**：
```groovy
export SPRING_DATASOURCE_URL=${SPRING_DATASOURCE_URL:-jdbc:postgresql://localhost:5432/mahjong_scoreboard_system}
```

## 配置对比

| 环境 | 端口 | 数据库名 | 状态 |
|------|------|----------|------|
| 生产环境 | 5432 | mahjong_scoreboard_system | ✅ |
| 测试环境 | 5432 | mahjong_scoreboard_system_test | ✅ |

## 优势

1. **统一端口**：两个环境使用相同的数据库端口（5432），简化配置管理
2. **标准配置**：使用 PostgreSQL 默认端口，符合最佳实践
3. **易于维护**：减少配置差异，降低出错概率
4. **环境隔离**：通过不同的数据库名实现环境隔离，而不是端口

## 验证配置

### 检查生产环境数据库

```bash
psql -h localhost -p 5432 -U yaohu -d mahjong_scoreboard_system -c "SELECT 1;"
```

### 检查测试环境数据库

```bash
psql -h localhost -p 5432 -U yaohu -d mahjong_scoreboard_system_test -c "SELECT 1;"
```

### 检查 PostgreSQL 监听端口

```bash
sudo netstat -tlnp | grep postgres
# 或
sudo ss -tlnp | grep postgres
```

应该看到：
```
tcp  0  0  127.0.0.1:5432  0.0.0.0:*  LISTEN  <PID>/postgres
```

## 注意事项

1. **数据库隔离**：虽然使用相同端口，但通过不同的数据库名实现环境隔离
   - 生产：`mahjong_scoreboard_system`
   - 测试：`mahjong_scoreboard_system_test`

2. **数据安全**：确保两个数据库的用户权限正确配置，避免测试环境误操作生产数据

3. **连接池配置**：
   - 生产环境：最大连接数 10，最小空闲 5
   - 测试环境：最大连接数 5，最小空闲 2

- **现在**：测试环境和生产环境统一使用端口 5432 ✅
- **原因**：简化配置，使用 PostgreSQL 标准端口
