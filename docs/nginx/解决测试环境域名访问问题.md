# 解决测试环境域名访问问题

## 问题分析

**当前状态**：
- ✅ 测试环境服务正常运行（`localhost:8082` 可访问）
- ❌ 域名访问失败（`test.yaohufox.com:8082` 无法访问）

**可能原因**：
1. DNS 未配置（`test.yaohufox.com` 无法解析）
2. 防火墙阻止外部访问 8082 端口
3. Nginx 未配置反向代理

## 解决方案

### 方案1：使用生产域名+端口（已配置，立即可用）✅

**已更新 Jenkinsfile**：
- 测试环境域名改为：`yaohufox.com:8082`
- 健康检查地址：`http://yaohufox.com:8082`

**验证**：
```bash
# 在服务器上测试
curl http://yaohufox.com:8082/api/test/hello

# 从外部测试（如果防火墙允许）
curl http://yaohufox.com:8082/api/test/hello
```

**如果仍然失败，检查防火墙**：
```bash
# 检查防火墙状态
ufw status
# 或
firewall-cmd --list-all

# 开放 8082 端口
ufw allow 8082/tcp
# 或
firewall-cmd --permanent --add-port=8082/tcp
firewall-cmd --reload
```

### 方案2：配置独立测试域名（长期方案）

如果需要使用 `test.yaohufox.com` 独立域名：

#### 步骤1：配置 DNS
在域名管理中添加 A 记录：
```
test.yaohufox.com  →  服务器IP
```

#### 步骤2：配置 Nginx 反向代理

创建配置文件：`/opt/yaohufox/config/nginx/sites-available/test.yaohufox.com`

```nginx
server {
    listen 80;
    server_name test.yaohufox.com;

    location / {
        proxy_pass http://localhost:8082;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置：
```bash
ln -s /opt/yaohufox/config/nginx/sites-available/test.yaohufox.com \
      /opt/yaohufox/config/nginx/sites-enabled/test.yaohufox.com

nginx -t
nginx -s reload
```

#### 步骤3：更新 Jenkinsfile

将 `TESTING_DOMAIN` 改回 `test.yaohufox.com`：
```groovy
TESTING_DOMAIN = 'test.yaohufox.com'
TESTING_DOMAIN_PORT = ''  // 使用标准端口，留空
```

## 常见问题

### Q1: 域名解析成功，但连接超时
**原因**：防火墙阻止外部访问
**解决**：开放 8082 端口

### Q2: 连接被拒绝
**原因**：服务只监听 127.0.0.1，不监听外部 IP
**解决**：检查应用配置，确保监听 `0.0.0.0:8082`

### Q3: DNS 解析失败
**原因**：域名未配置或 DNS 未生效
**解决**：
- 等待 DNS 生效（最多 24 小时）
- 或使用方案1（生产域名+端口）
