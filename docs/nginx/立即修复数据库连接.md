# 立即修复数据库连接问题

## 问题

错误：`Connection to localhost:5433 refused`

测试环境配置使用端口 **5433**，但 PostgreSQL 可能未在该端口监听。

## 立即执行以下命令

### 1. 检查 PostgreSQL 服务状态和端口

```bash
# 检查 PostgreSQL 服务状态
sudo systemctl status postgresql

# 检查 PostgreSQL 监听的端口
sudo netstat -tlnp | grep postgres
# 或
sudo ss -tlnp | grep postgres
```

### 2. 测试数据库连接

```bash
# 测试默认端口 5432
psql -h localhost -p 5432 -U yaohu -d postgres -c "SELECT 1;"

# 测试端口 5433
psql -h localhost -p 5433 -U yaohu -d postgres -c "SELECT 1;"
```

### 3. 检查测试数据库是否存在

```bash
# 在端口 5432 上检查
psql -h localhost -p 5432 -U yaohu -l | grep mahjong_scoreboard_system_test

# 如果数据库不存在，创建它
createdb -h localhost -p 5432 -U yaohu mahjong_scoreboard_system_test
```

## 解决方案

### 方案1：修改应用配置使用端口 5432（推荐）

如果 PostgreSQL 运行在默认端口 5432，修改应用配置：

**修改文件**：`mahjong-scoreboard-start/src/main/resources/application-testing.yml`

```yaml
spring:
  datasource:
    url: ${SPRING_DATASOURCE_URL:jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test}
```

**同时更新 Jenkinsfile** 中的默认值：

```groovy
export SPRING_DATASOURCE_URL=${SPRING_DATASOURCE_URL:-jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test}
```

### 方案2：配置 PostgreSQL 监听端口 5433

如果必须使用端口 5433：

1. **编辑 PostgreSQL 配置**：
   ```bash
   # 找到配置文件
   sudo find /etc -name postgresql.conf 2>/dev/null
   # 或
   sudo -u postgres psql -c "SHOW config_file;"
   ```

2. **修改配置**：
   ```bash
   sudo nano /etc/postgresql/*/main/postgresql.conf
   # 或
   sudo nano /var/lib/pgsql/*/data/postgresql.conf
   ```
   
   添加或修改：
   ```
   port = 5433
   # 或同时监听多个端口
   port = 5432,5433
   ```

3. **重启 PostgreSQL**：
   ```bash
   sudo systemctl restart postgresql
   ```

## 快速修复步骤（推荐方案1）

```bash
# 1. 检查 PostgreSQL 端口
sudo netstat -tlnp | grep postgres

# 2. 如果显示 5432，修改应用配置
cd /path/to/mahjong-scoreboard
# 编辑 application-testing.yml，将 5433 改为 5432

# 3. 确保测试数据库存在
psql -h localhost -p 5432 -U yaohu -d postgres -c "CREATE DATABASE mahjong_scoreboard_system_test;" 2>/dev/null || echo "数据库已存在"

# 4. 重新部署
# 通过 Jenkins 重新部署，或手动启动服务
```
