# 立即诊断服务未运行问题

## 问题描述

Jenkins 显示部署成功，但服务未运行。

## 立即执行以下命令

### 1. 检查 PID 文件和日志

```bash
cd /opt/yaohufox/testing

# 检查 PID 文件
cat app.pid 2>/dev/null || echo "PID 文件不存在"

# 检查进程是否存在
if [ -f app.pid ]; then
    PID=$(cat app.pid)
    ps -p $PID || echo "进程不存在"
fi

# 查看完整日志（最重要！）
tail -100 app.log
```

### 2. 查看日志中的错误

```bash
cd /opt/yaohufox/testing

# 查看所有错误
grep -i "error\|exception\|failed\|fatal" app.log | tail -30

# 查看最后启动尝试
tail -50 app.log
```

### 3. 手动尝试启动服务

```bash
cd /opt/yaohufox/testing

# 检查 JAR 文件是否存在
ls -lh app.jar

# 尝试前台启动（可以看到错误信息）
java -jar \
  -Dspring.profiles.active=testing \
  -Dserver.port=8082 \
  -Dspring.datasource.url=jdbc:postgresql://localhost:5433/mahjong_scoreboard_system_test \
  -Dspring.datasource.username=yaohu \
  -Dspring.datasource.password=cch815566 \
  app.jar
```

**注意**：这会显示启动时的所有错误信息，按 Ctrl+C 停止。

## 常见原因和解决方案

### 原因1：数据库连接失败

**症状**：日志中出现数据库连接错误

**解决**：
```bash
# 检查数据库是否运行
ps aux | grep postgres

# 检查数据库连接
psql -h localhost -p 5433 -U yaohu -d mahjong_scoreboard_system_test -c "SELECT 1;"
```

### 原因2：端口被占用

**症状**：日志显示端口已被占用

**解决**：
```bash
# 查找占用端口的进程
lsof -i :8082
# 或
netstat -tlnp | grep 8082

# 停止占用端口的进程
kill -9 <PID>
```

### 原因3：配置文件错误

**症状**：日志显示配置文件解析错误

**解决**：检查 `application-testing.yml` 配置

### 原因4：内存不足

**症状**：日志显示 OutOfMemoryError

**解决**：增加 JVM 内存参数或检查系统内存

### 原因5：Jenkins 健康检查误判

**症状**：Jenkins 显示成功，但服务实际未运行

**可能原因**：
- 健康检查回退到 localhost 检查，但服务只运行了很短时间
- PID 文件存在但进程已退出

**解决**：查看 Jenkins 部署日志，检查健康检查的详细输出


3. **检查环境变量**：


