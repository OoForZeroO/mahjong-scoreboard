# 手动启动测试环境 - 正确命令

## 问题

手动启动失败，错误显示连接 `localhost:5433`，但配置已改为 5432。

**原因**：启动命令中可能使用了错误的端口或环境变量覆盖了配置。

## 正确的启动命令

### 方法1：使用脚本启动（推荐）

```bash
cd /path/to/mahjong-scoreboard
chmod +x docs/nginx/正确启动测试环境服务.sh
bash docs/nginx/正确启动测试环境服务.sh
```

### 方法2：手动启动（完整命令）

```bash
cd /opt/yaohufox/testing

# 停止旧进程（如果有）
if [ -f app.pid ]; then
    kill $(cat app.pid) 2>/dev/null
    rm -f app.pid
fi

# 启动服务（关键：使用端口 5432，不是 5433）
nohup java -jar \
  -Dspring.profiles.active=testing \
  -Dserver.port=8082 \
  -Dserver.address=0.0.0.0 \
  -Dspring.datasource.url=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test \
  -Dspring.datasource.username=yaohu \
  -Dspring.datasource.password=cch815566 \
  app.jar > app.log 2>&1 &

echo $! > app.pid
echo "PID: $(cat app.pid)"

# 等待启动
sleep 15

# 验证
ps aux | grep java | grep 8082
netstat -tlnp | grep 8082
curl http://localhost:8082/api/test/hello
```

## 关键点

### 1. 数据库端口必须是 5432

**错误**：
```bash
-Dspring.datasource.url=jdbc:postgresql://localhost:5433/...  # ❌ 错误
```

**正确**：
```bash
-Dspring.datasource.url=jdbc:postgresql://localhost:5432/...  # ✅ 正确
```

### 2. 监听地址必须是 0.0.0.0

**错误**：
```bash
# 不指定 address，默认只监听 localhost
```

**正确**：
```bash
-Dserver.address=0.0.0.0  # 监听所有网络接口
```

### 3. 检查环境变量

如果存在 `.env` 文件，检查是否覆盖了配置：

```bash
cd /opt/yaohufox/testing
cat .env | grep DATASOURCE
```

如果 `.env` 文件中包含 `SPRING_DATASOURCE_URL` 且使用 5433，需要修改或删除。

## 常见错误

### 错误1：使用错误的端口

```bash
# ❌ 错误：使用 5433
-Dspring.datasource.url=jdbc:postgresql://localhost:5433/...
```

**解决**：改为 5432

### 错误2：环境变量覆盖

如果 `.env` 文件中有：
```
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5433/...
```

**解决**：
1. 修改 `.env` 文件，改为 5432
2. 或在启动命令中显式指定（会覆盖环境变量）

### 错误3：未指定监听地址

```bash
# ❌ 错误：不指定 address
-Dserver.port=8082
```

**解决**：添加 `-Dserver.address=0.0.0.0`

## 完整启动流程

```bash
# 1. 进入目录
cd /opt/yaohufox/testing

# 2. 检查并停止旧进程
if [ -f app.pid ]; then
    PID=$(cat app.pid)
    if ps -p $PID > /dev/null 2>&1; then
        kill $PID
        sleep 3
    fi
    rm -f app.pid
fi

# 3. 检查数据库连接（使用 5432）
psql -h localhost -p 5432 -U yaohu -d mahjong_scoreboard_system_test -c "SELECT 1;" || {
    echo "数据库连接失败，请检查数据库"
    exit 1
}

# 4. 启动服务（关键：端口 5432，监听 0.0.0.0）
nohup java -jar \
  -Dspring.profiles.active=testing \
  -Dserver.port=8082 \
  -Dserver.address=0.0.0.0 \
  -Dspring.datasource.url=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test \
  -Dspring.datasource.username=yaohu \
  -Dspring.datasource.password=cch815566 \
  app.jar > app.log 2>&1 &

echo $! > app.pid

# 5. 等待启动
echo "等待服务启动..."
sleep 15

# 6. 验证
echo "检查进程："
ps aux | grep java | grep 8082

echo "检查端口："
netstat -tlnp | grep 8082

echo "测试接口："
curl http://localhost:8082/api/test/hello
```

## 如果仍然失败

### 检查日志

```bash
tail -50 /opt/yaohufox/testing/app.log
```

查看具体错误信息。

### 检查环境变量

```bash
cd /opt/yaohufox/testing
cat .env 2>/dev/null | grep -i datasource
```

如果 `.env` 文件中有错误的配置，修改它。

### 前台启动查看错误

```bash
cd /opt/yaohufox/testing
java -jar \
  -Dspring.profiles.active=testing \
  -Dserver.port=8082 \
  -Dserver.address=0.0.0.0 \
  -Dspring.datasource.url=jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test \
  -Dspring.datasource.username=yaohu \
  -Dspring.datasource.password=cch815566 \
  app.jar
```

前台启动可以看到所有错误信息，按 Ctrl+C 停止。

## 验证清单

启动后检查：

- [ ] 进程运行：`ps aux | grep java | grep 8082`
- [ ] 端口监听：`netstat -tlnp | grep 8082`（应该显示 `0.0.0.0:8082`）
- [ ] 本地访问：`curl http://localhost:8082/api/test/hello`
- [ ] 日志无错误：`tail -20 app.log`（不应该有 5433 相关错误）

## 重要提醒

**确保使用端口 5432，不是 5433！**

如果启动命令中显式指定了数据库 URL，必须使用：
```
jdbc:postgresql://localhost:5432/mahjong_scoreboard_system_test
```

而不是：
```
jdbc:postgresql://localhost:5433/mahjong_scoreboard_system_test  # ❌ 错误
```
