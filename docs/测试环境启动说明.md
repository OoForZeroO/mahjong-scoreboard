# 测试环境启动说明

## 端口配置

测试环境统一使用 **8082** 端口。

## 启动方式

### 方式一：使用 Jenkins 自动部署（推荐）

Jenkins 会自动使用 `testing` profile 和 8082 端口部署到测试环境。

### 方式二：手动启动（在服务器上）

在测试环境目录（如 `/opt/yaohufox/testing`）下执行：

```bash
# 方式1：使用环境变量指定端口和 profile
export SERVER_PORT=8082
export SPRING_PROFILES_ACTIVE=testing
java -jar app.jar

# 方式2：使用命令行参数（推荐）
java -jar app.jar \
  --spring.profiles.active=testing \
  -Dserver.port=8082

# 方式3：后台运行
nohup java -jar app.jar \
  --spring.profiles.active=testing \
  -Dserver.port=8082 \
  > app.log 2>&1 &
echo $! > app.pid
```

### 方式三：使用项目启动脚本

```bash
# 在项目根目录执行
./scripts/unix/start.sh
```

该脚本会自动使用 `testing` profile。

## 验证启动

启动后检查：

```bash
# 1. 检查进程
ps aux | grep java | grep mahjong

# 2. 检查端口监听
ss -tlnp | grep 8082
# 或
netstat -tlnp | grep 8082

# 3. 测试健康检查
curl http://localhost:8082/actuator/health

# 4. 测试接口
curl http://localhost:8082/api/test/hello
```

## 常见问题

### 问题1：端口 8080 已被占用

**原因**：未使用 `testing` profile，使用了默认配置（端口 8080）。

**解决**：确保启动时指定 `--spring.profiles.active=testing`。

### 问题2：端口 8082 已被占用

**解决**：
```bash
# 查找占用 8082 端口的进程
lsof -i :8082
# 或
ss -tlnp | grep 8082

# 停止旧进程（根据实际情况调整）
kill <PID>
```

### 问题3：数据库连接失败

**常见错误**：
- `FATAL: database "mahjong_scoreboard_system_test" does not exist` → 数据库不存在，参考 `docs/数据库不存在-创建与修复.md`
- `FATAL: password authentication failed for user "yaohu"` → 用户认证失败，参考 `docs/测试环境数据库用户认证失败-修复.md`

**快速检查**：
```bash
# 1. 检查数据库是否存在
sudo -u postgres psql -l | grep mahjong_scoreboard_system_test

# 2. 检查用户是否存在
sudo -u postgres psql -c "\du yaohu"

# 3. 测试用户连接
PGPASSWORD=cch815566 psql -h localhost -U yaohu -d mahjong_scoreboard_system_test -c "SELECT 1;"

# 4. 查看应用日志
tail -f app.log | grep -i "database\|connection\|error"
```

**详细修复步骤**：请参考 `docs/测试环境数据库用户认证失败-修复.md`
