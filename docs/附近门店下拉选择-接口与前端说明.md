# 附近门店下拉选择（输入框 + 当前坐标搜索）

## 功能说明

在需要选择「棋牌门店」的页面（如开桌、记录对局），使用**输入框 + 下拉选择**：下拉选项来自**当前坐标下从互联网（高德 POI）搜索到的棋牌门店列表**；用户**选择后再将选中项落库**，无需事先批量同步。

## 推荐流程（前端触发 → 选后落库）

1. **前端获取定位** → 调用 `GET /api/rooms/search-from-poi?latitude=xx&longitude=xx&radiusKm=10`，从互联网拉取「棋牌」相关 POI 列表（**不落库**）。
2. **前端展示下拉列表** → 用返回的 `RoomPoiItem` 展示（名称、地址、距离等），用户选择一项。
3. **前端提交选中项落库** → 调用 `POST /api/rooms/save-from-poi`，Body 为选中的那条数据（含 `externalId`、`name`、`latitude`、`longitude`、`address`）。后端若该 `externalId` 已存在则直接返回已存在记录，否则写入 `rooms` 表。
4. **后续使用** → 落库后该门店会出现在 `GET /api/rooms/nearby` 中，也可直接用返回的 `Room` 的 `id`/`name` 参与业务（如开桌、记录对局）。

## 后端接口

### 1. 从互联网搜索棋牌室（仅返回列表，不落库）

- **URL**: `GET /api/rooms/search-from-poi`
- **参数**: `latitude`（必填）、`longitude`（必填）、`radiusKm`（可选，默认 10，单位公里）
- **响应**: 数组，每项为 `RoomPoiItem`：`externalId`、`name`、`address`、`latitude`、`longitude`、`distanceKm`。未配置高德 Key 返回 `503`。

### 2. 将选中的门店落库

- **URL**: `POST /api/rooms/save-from-poi`
- **Body**: `{ "externalId": "必填", "name": "", "latitude": 0, "longitude": 0, "address": "可选" }`
- **响应**: `201` + 保存或已存在的 `Room` 实体。

### 3. 按坐标搜索附近门店（查库）

- **URL**: `GET /api/rooms/nearby`
- **参数**: `latitude`、`longitude`（必填），`radius`（可选，公里）。只返回**已落库**且填写了经纬度的门店，按距离排序。

### 4. 可选：批量从 POI 同步落库（后台/管理用）

- **URL**: `POST /api/rooms/sync-from-poi`
- **说明**: 按坐标+半径一次性将高德 POI 结果全部写入 `rooms`。主流程推荐用「search-from-poi + save-from-poi」按需落库。高德 Key 配置：`amap.api.key` 或环境变量 `AMAP_API_KEY`，申请地址 https://console.amap.com/dev/key/app。

## 数据库

- 门店表 `rooms` 字段：`id`、`name`、`logo`、`latitude`、`longitude`、`address`、`external_id`（高德 POI 唯一标识，用于去重）、`create_time`、`update_time`。
- 迁移脚本：`add_rooms_latitude_longitude.sql`、`add_rooms_address_external_id.sql`（若使用 JPA `ddl-auto=update` 可依赖自动建表）。

## 前端实现要点（如微信小程序）

1. **获取定位**  
   使用 `wx.getLocation` 获取当前经纬度（需在 app.json 或页面配置中声明定位权限）。

2. **拉取互联网列表（不落库）**  
   进入页面或点击输入框时，调用 `GET /api/rooms/search-from-poi?latitude=xx&longitude=xx&radiusKm=10`，用返回列表做下拉数据源。展示文案示例：`{{item.name}}（约 {{item.distanceKm}} km）` 或附带 `item.address`。

3. **用户选择后落库**  
   用户选中一项后，将该条的 `externalId`、`name`、`latitude`、`longitude`、`address` 作为 Body 调用 `POST /api/rooms/save-from-poi`，拿到返回的 `Room`（含 `id`），将 `id` 或 `name` 写入表单，用于后续开桌/记录对局等。

4. **可选**  
   - 定位失败时：可降级调用 `GET /api/rooms` 获取已落库的全部门店，或提示用户配置高德 Key 后使用 search-from-poi。
   - 若希望下拉里同时包含「已选过的门店」，可先调 `GET /api/rooms/nearby` 再调 `search-from-poi`，前端合并去重（按 `id`/`externalId`）展示。

## 相关代码

- 实体：`Room`（`latitude`、`longitude`、`address`、`externalId`）
- DTO：`RoomNearbyItem`（库内附近门店）、`RoomPoiItem`（互联网 POI 项）、`RoomFromPoiRequest`（选后落库请求）
- 接口：`GET /api/rooms/search-from-poi`、`POST /api/rooms/save-from-poi`、`GET /api/rooms/nearby`、`POST /api/rooms/sync-from-poi`
- 服务：`RoomPoiSyncService.searchFromPoi`、`saveFromPoi`、`syncFromPoi`；`RoomService.findNearby`
