# 附近门店下拉选择（输入框 + 当前坐标搜索）

## 功能说明

在需要选择「棋牌门店」的页面（如开桌、记录对局），使用**输入框 + 下拉选择**：下拉选项来自**当前坐标下搜索到的棋牌门店列表**，并可展示距离（如「约 1.2 km」）。

## 后端接口

### 按坐标搜索附近门店

- **URL**: `GET /api/rooms/nearby`
- **参数**:
  - `latitude`（必填）：纬度
  - `longitude`（必填）：经度
  - `radius`（可选）：半径（公里）。不传则不限制距离，仅按距离排序返回所有有坐标的门店

- **响应示例**:
```json
[
  { "id": 1, "name": "快乐棋牌室", "logo": "...", "distanceKm": 0.85 },
  { "id": 2, "name": "休闲麻将馆", "logo": "...", "distanceKm": 1.23 }
]
```

- 仅返回在 `rooms` 表中已填写 `latitude`、`longitude` 的门店，按距离升序。

## 数据库

- 门店表 `rooms` 已增加字段：`latitude`、`longitude`（均为可选）。
- 执行迁移：`database/migrations/add_rooms_latitude_longitude.sql`  
  （若使用 MySQL 且不支持 `ADD COLUMN IF NOT EXISTS`，可改为两条普通 `ALTER TABLE rooms ADD COLUMN ...`）

## 前端实现要点（如微信小程序）

1. **获取定位**  
   使用 `wx.getLocation` 获取当前经纬度（需在 app.json 或页面配置中声明定位权限）。

2. **请求附近门店**  
   进入页面或点击输入框时，用当前 `latitude`、`longitude` 调用 `GET /api/rooms/nearby`，可选传 `radius`（如 10 表示 10 公里内）。

3. **输入框 + 下拉**  
   - 输入框：placeholder 如「选择/搜索门店」，可只读或可输入（若后续支持关键词搜索可在此输入）。
   - 下拉：用小程序组件（如 `picker`、自定义 `dropdown` 或带 `popup` 的列表）展示接口返回的 `RoomNearbyItem` 列表。
   - 展示文案示例：`{{item.name}}（约 {{item.distanceKm}} km）`。
   - 选中一项后，将 `id` 或 `name` 回填到表单（与现有「房间名称」逻辑一致即可）。

4. **可选增强**  
   - 支持输入关键词后再请求：后端可增加 `keyword` 参数，做「附近 + 关键词」筛选（当前接口仅按坐标与距离）。
   - 定位失败时：可降级为调用 `GET /api/rooms` 获取全部门店列表供选择。

## 相关代码

- 实体：`Room`（`latitude`、`longitude`）
- DTO：`RoomNearbyItem`（id, name, logo, distanceKm）
- 接口：`RoomController.getNearbyRooms`、`RoomService.findNearby`、`RoomRepository.findByLatitudeIsNotNullAndLongitudeIsNotNull`
