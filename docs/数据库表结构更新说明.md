# 数据库表结构更新说明

## 概述

根据新的麻将对局数据库表结构设计文档，对现有数据库表结构和代码进行了全面更新。

## 主要变更

### 1. matches表
- **移除字段**: `room_id`, `current_round`
- **修改字段**: `room_name` 改为可空（NULL）
- **保留字段**: `match_id`, `room_name`, `start_time`, `end_time`, `status`, `total_rounds`, `settlement_multiplier`, `create_time`, `update_time`

### 2. match_participants表
- **移除字段**: `seat_position`, `is_winner`, `final_score`, `is_quit`, `quit_time`, `wechat_user_id`, `nickname`, `avatar`
- **修改字段**: 
  - `id` 重命名为 `participant_id`
  - `user_id` 改为可空，关联 `wechat_users` 表
  - 新增 `user_name` 字段
- **保留字段**: `participant_id`, `match_id`, `user_id`, `user_name`, `total_score`, `create_time`, `update_time`

### 3. round_scores表
- **修改字段**: 
  - `id` 重命名为 `score_id`
  - 新增 `round_time` 字段
- **保留字段**: `score_id`, `match_id`, `participant_id`, `round_number`, `round_time`, `score`, `cumulative_score`, `create_time`, `update_time`

### 4. match_results表
- **修改字段**: 
  - 新增 `result_id` 作为主键
  - `match_id` 改为唯一约束
  - 移除 `total_scores`, `completion_time`, `update_time` 字段
  - 新增 `total_duration` 字段
- **保留字段**: `result_id`, `match_id`, `winner_id`, `highest_score`, `lowest_score`, `total_duration`, `create_time`

## 代码更新

### 模型类更新
1. **Match.java**: 移除 `room` 和 `currentRound` 字段
2. **MatchParticipant.java**: 
   - 移除多个字段（`isWinner`, `seatPosition` 等）
   - 将 `user` 字段类型改为 `WechatUser`
   - 字段名改为 `userName`
3. **RoundScore.java**: 新增 `roundTime` 字段
4. **MatchResult.java**: 新增 `resultId` 主键和 `totalDuration` 字段

### 服务层更新
1. **MatchServiceImpl.java**:
   - `createMatch`: 简化逻辑，不再验证 room 对象
   - `updateMatch`: 移除 room 和 currentRound 相关逻辑
   - `quitMatch`: 改为直接删除参与者
   - 移除所有 `finalScore` 相关逻辑
   - 排序逻辑改为使用 `totalScore`

### 控制器更新
1. **MatchController.java**: 移除 room 验证逻辑

## API变更

### 创建对局接口变更
**之前**:
```json
{
  "room": {
    "id": 1,
    "name": "快乐棋牌室"
  },
  "roomName": "快乐棋牌室"
}
```

**现在**:
```json
{
  "roomName": "快乐棋牌室"
}
```

### 添加参与者接口变更
**之前**:
```json
{
  "userId": 1,
  "nickname": "玩家1",
  "avatar": "http://example.com/avatar.jpg"
}
```

**现在**:
```json
{
  "user": {
    "id": 1
  },
  "userName": "玩家1"
}
```

## 数据库迁移

执行 `update_database_schema.sql` 脚本进行数据库迁移：

```bash
psql -U postgres -d mahjongdb -f update_database_schema.sql
```

## 注意事项

1. **数据迁移**: 如果现有数据库中有数据，需要先备份
2. **外键约束**: `match_participants.user_id` 现在关联 `wechat_users` 表
3. **游客支持**: `user_id` 可为空，支持游客参与对局
4. **唯一约束**: 移除了 `uk_match_user` 约束，允许多名游客参与同一对局
