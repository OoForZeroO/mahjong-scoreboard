# 启动报错「database does not exist」— 创建与修复

## 错误说明

启动时出现类似：

```text
org.postgresql.util.PSQLException: FATAL: database "xxx" does not exist
```

表示应用连接的 PostgreSQL 数据库尚未创建，需要先在服务器上创建对应库（以及可选用户），再执行表结构初始化。

---

## 项目里使用的数据库名（统一规范）

| 运行方式 | 数据库名 |
|----------|----------|
| 默认（未指定 profile） | `mahjong_scoreboard_system_test`（与测试环境一致） |
| 测试环境 `--spring.profiles.active=testing` | `mahjong_scoreboard_system_test` |
| 生产环境 `--spring.profiles.active=production` | `mahjong_scoreboard_system` |

**不再使用** `mahjong_score_system`。若报错里是该库名，请改为创建上表中的一个库。

---

## 一、创建数据库（必做）

在**已安装 PostgreSQL 的服务器**上执行（用有建库权限的账号，如 `postgres`）。按需创建**测试库**和/或**生产库**：

```bash
# 测试环境 / 默认（本地开发）使用的库
sudo -u postgres psql -c "CREATE DATABASE mahjong_scoreboard_system_test ENCODING 'UTF8';"

# 生产环境使用的库
sudo -u postgres psql -c "CREATE DATABASE mahjong_scoreboard_system ENCODING 'UTF8';"
```

若需要指定 locale（可选）：

```bash
sudo -u postgres psql
```

在 psql 里执行：

```sql
CREATE DATABASE mahjong_scoreboard_system_test WITH ENCODING 'UTF8' TEMPLATE = template0;
CREATE DATABASE mahjong_scoreboard_system WITH ENCODING 'UTF8' TEMPLATE = template0;
\q
```

---

## 二、创建应用用户并授权（推荐）

若应用不用 `postgres` 而用独立用户（如 `yaohu`），需先建用户并授权：

```bash
sudo -u postgres psql -c "CREATE USER yaohu WITH PASSWORD '你的密码';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE mahjong_score_system TO yaohu;"
sudo -u postgres psql -d mahjong_score_system -c "GRANT ALL ON SCHEMA public TO yaohu;"
sudo -u postgres psql -d mahjong_score_system -c "ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO yaohu;"
```

然后在 `application.properties` 或环境变量里把 `spring.datasource.username` / `spring.datasource.password` 改成该用户和密码。

---

## 三、初始化表结构（首次部署必做）

数据库建好后，对**每个库**分别执行项目里的建表脚本。在项目根目录执行：

```bash
# 测试库
sudo -u postgres psql -d mahjong_scoreboard_system_test -f database/migrations/db-init-simple.sql

# 生产库
sudo -u postgres psql -d mahjong_scoreboard_system -f database/migrations/db-init-simple.sql
```

若使用 `yaohu` 用户，则：

```bash
psql -h localhost -U yaohu -d mahjong_scoreboard_system_test -f database/migrations/db-init-simple.sql
psql -h localhost -U yaohu -d mahjong_scoreboard_system -f database/migrations/db-init-simple.sql
```

执行成功后，再启动应用即可。

---

## 四、小结：只使用两个库

- **测试 / 默认**：`mahjong_scoreboard_system_test`
- **生产**：`mahjong_scoreboard_system`

按上面一、三对两个库分别建库并执行 `db-init-simple.sql` 即可。

---

## 五、启动方式与数据库对应关系

- **默认（不指定 profile）**：连接 `mahjong_scoreboard_system_test`，端口 8080。
- **测试环境**：`java -jar app.jar -Dspring.profiles.active=testing` → 连接 `mahjong_scoreboard_system_test`，端口 8082。
- **生产环境**：`java -jar app.jar -Dspring.profiles.active=production` → 连接 `mahjong_scoreboard_system`，端口 8081。

完成「一 + 三」后按需启动；若使用独立用户，再完成「二」并修改配置中的用户名与密码。
