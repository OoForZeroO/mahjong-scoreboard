## 环境设置选项

### 选项1：使用PostgreSQL（已安装，推荐）

您已本地安装了PostgreSQL 9.3版本，我们已为您配置好相关环境：

```bash
# 运行PostgreSQL示例程序测试数据交互
scripts\run_postgresql_example.bat
```

**PostgreSQL环境配置说明**：
- PostgreSQL版本：9.3
- 数据库名称：devdb
- 用户名：devuser
- 密码：devpassword
- 端口：5432


### 选项3：使用SQLite轻量级替代方案

SQLite是一个无需安装的轻量级数据库，适合快速开发和测试：

#### Java安装

1. 下载并安装JDK 11或更高版本
2. 配置JAVA_HOME环境变量指向JDK安装目录
3. 将%JAVA_HOME%\bin添加到系统PATH

### 选项3：使用SQLite轻量级替代方案

SQLite是一个无需安装的轻量级数据库，非常适合开发和测试：

**快速开始**：

1. 查看SQLite快速入门指南：
   ```bash
   notepad.exe d:\YH\SQLite快速指南.txt
   ```

2. 运行SQLite示例程序测试数据交互：
   ```bash
   scripts\run_sqlite_example.bat
   ```

**SQLite优势**：
- 无需安装，一个文件即可运行
- 轻量级，资源消耗低
- 完全兼容基本SQL语法
- 数据库文件易于备份和共享

## Java项目配置

### 数据库连接配置

#### PostgreSQL连接配置（已配置）

```properties
# application.properties - PostgreSQL配置
spring.datasource.url=jdbc:postgresql://localhost:5432/devdb
spring.datasource.username=devuser
spring.datasource.password=devpassword
spring.datasource.driver-class-name=org.postgresql.Driver
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect
```

完整的PostgreSQL配置文件位置：
```
config/postgresql_config.properties
```

#### SQLite连接配置

```properties
# application.properties - SQLite配置
spring.datasource.url=jdbc:sqlite:d:\\YH\\data.db
spring.datasource.driver-class-name=org.sqlite.JDBC
spring.datasource.username=
spring.datasource.password=
spring.jpa.hibernate.ddl-auto=create
spring.jpa.database-platform=org.hibernate.community.dialect.SQLiteDialect
```

## 测试数据库连接

### 测试PostgreSQL连接

```bash
# 使用psql命令行工具连接
psql -U devuser -d devdb

# 或运行示例程序测试
scripts\run_postgresql_example.bat
```

### 测试SQLite连接

运行我们提供的SQLite示例程序：

```bash
scripts\run_sqlite_example.bat
```

该脚本会：
1. 检查Java环境
2. 使用Maven编译项目
3. 运行SQLite连接示例
4. 创建测试数据库和表
5. 插入和查询测试数据

## 常见问题排查

### Java环境问题

- 确保JDK已正确安装：
  ```bash
  java -version
  ```

- 检查环境变量配置：
  ```bash
  echo %JAVA_HOME%
  ```

### PostgreSQL连接问题

- 确保PostgreSQL服务（postgresql-x64-9.3）正在运行
- 检查密码是否正确，默认尝试的是'postgres'
- 如果连接被拒绝，可能需要修改pg_hba.conf文件以允许密码认证


### SQLite相关问题

- 确保SQLite JDBC驱动已添加到项目依赖
- 检查文件路径权限（确保应用程序有权限读写数据库文件）
