# 测试环境访问方案

## 当前情况

✅ **测试环境服务正常运行**：`curl http://localhost:8082/actuator/health` 成功  
❌ **域名未配置**：`test.yaohufox.com` 无法解析

## 解决方案

### 方案1：使用生产域名 + 端口（推荐，立即可用）

测试环境可以通过生产域名 + 8082端口访问：

**访问地址**：
```
https://yaohufox.com:8082
```
或
```
http://yaohufox.com:8082
```

**验证**：
```bash
# 在服务器上测试
curl http://localhost:8082/api/test/hello

# 从外部访问（如果防火墙允许）
curl https://yaohufox.com:8082/api/test/hello
curl http://yaohufox.com:8082/api/test/hello
```

**Postman 配置**：
- `base_url`: `https://yaohufox.com:8082` 或 `http://yaohufox.com:8082`

### 方案2：配置 Nginx 反向代理（推荐，长期方案）

为测试环境配置独立的域名访问。

#### 2.1 配置 DNS

在域名管理中添加 A 记录：
```
test.yaohufox.com  →  服务器IP
```

#### 2.2 配置 Nginx

创建或编辑 Nginx 配置文件：`/etc/nginx/sites-available/test.yaohufox.com`

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name test.yaohufox.com;

    # SSL 证书配置（如果使用HTTPS）
    ssl_certificate /path/to/ssl/cert.pem;
    ssl_certificate_key /path/to/ssl/key.pem;

    # 反向代理到测试环境
    location / {
        proxy_pass http://localhost:8082;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持（如果需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 健康检查
    location /actuator/health {
        proxy_pass http://localhost:8082/actuator/health;
        access_log off;
    }
}
```

#### 2.3 启用配置

```bash
# 创建软链接
ln -s /etc/nginx/sites-available/test.yaohufox.com /etc/nginx/sites-enabled/

# 测试配置
nginx -t

# 重载 Nginx
systemctl reload nginx
```

#### 2.4 验证

```bash
curl https://test.yaohufox.com/api/test/hello
```

**Postman 配置**：
- `base_url`: `https://test.yaohufox.com`

### 方案3：使用服务器IP + 端口

如果域名暂时无法配置，可以使用服务器IP：

**访问地址**：
```
http://服务器IP:8082
```

**Postman 配置**：
- `base_url`: `http://您的服务器IP:8082`

**注意**：需要确保防火墙允许外部访问8082端口。

## 防火墙配置（如果需要）

如果外部无法访问8082端口，需要开放防火墙：

```bash
# Ubuntu/Debian
ufw allow 8082/tcp

# CentOS/RHEL
firewall-cmd --permanent --add-port=8082/tcp
firewall-cmd --reload
```
