# Postman 连接问题快速诊断

## 当前问题

错误：`getaddrinfo ENOTFOUND test.yaohufox.com`

**原因**：`test.yaohufox.com` 域名不存在或无法解析。

## 立即尝试的解决方案

### 方案1：使用生产域名 + 端口（最可能）

在 Postman 中：
1. 点击右上角 "测试环境" → "Edit"
2. 将 `base_url` 改为：`https://yaohufox.com:8082`
3. 保存并测试

如果 HTTPS 不行，试试：`http://yaohufox.com:8082`

### 方案2：使用生产环境（临时）

如果测试环境暂时不可用：
1. 选择 "生产环境"
2. 测试接口应该能正常工作

## 快速测试脚本

在浏览器中依次访问以下地址，看哪个能正常返回 `Hello World!`：

```
1. https://yaohufox.com:8082/api/test/hello
2. http://yaohufox.com:8082/api/test/hello
3. https://yaohufox.com/api/test/hello  (生产环境)
```

能访问的地址就是正确的配置。

## 在 Postman 中修改步骤

1. **打开环境编辑**
   - 右上角点击环境选择器
   - 点击 "测试环境" 右侧的 "..." → "Edit"

2. **修改 base_url**
   ```
   Current Value: https://yaohufox.com:8082
   ```
   或
   ```
   Current Value: http://yaohufox.com:8082
   ```

3. **保存并测试**
   - 点击 "Save"
   - 选择 "测试环境"
   - 运行 "健康检查" 接口

## 如果仍然失败

请提供以下信息：
1. 测试环境是否在生产服务器上？
2. 测试环境的实际访问地址是什么？
3. 在浏览器中能访问测试接口吗？

---

**最可能的原因**：测试环境使用 `https://yaohufox.com:8082` 或 `http://yaohufox.com:8082`，请先尝试这两个地址。
