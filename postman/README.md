# Postman 接口测试快速开始

## 📦 文件说明

本目录包含 Postman 接口测试所需的所有配置文件：

- **生产环境.postman_environment.json** - 生产环境配置
- **测试环境.postman_environment.json** - 测试环境配置
- **麻将计分系统API接口.postman_collection.json** - 接口集合文件
- **Postman使用指南.md** - 详细使用说明

## 🚀 快速开始（3步）

### 第1步：导入环境配置

1. 打开 Postman
2. 点击右上角 **"Environments"** → **"Import"**
3. 选择以下文件：
   - `生产环境.postman_environment.json`
   - `测试环境.postman_environment.json`

### 第2步：导入接口集合

1. 点击左侧 **"Collections"** → **"Import"**
2. 选择 `麻将计分系统API接口.postman_collection.json`
3. 导入完成后，左侧会显示接口集合

### 第3步：选择环境并测试

1. 点击右上角环境选择器，选择 **"测试环境"** 或 **"生产环境"**
2. 打开 `测试接口` → `健康检查`
3. 点击 **"Send"** 按钮
4. 如果返回 `Hello World!`，说明配置成功！

## 📋 环境配置说明

### 生产环境
- **URL**: `https://yaohufox.com`
- **端口**: 8081（通过Nginx代理）

### 测试环境
- **URL**: `http://localhost:8082`
- **端口**: 8082

## 🔄 切换环境

在 Postman 右上角的环境选择下拉框中切换：
- **生产环境** - 测试线上服务
- **测试环境** - 测试本地服务

切换后，所有接口的 `{{base_url}}` 会自动更新。

## 💡 常用功能

### 1. 自动保存ID到环境变量

部分接口（如"创建对局"、"添加参与者"）已配置自动保存功能：
- 创建对局后，`test_match_id` 会自动更新
- 添加参与者后，`test_participant_id` 会自动更新

### 2. 使用环境变量

在请求中使用 `{{变量名}}` 引用环境变量：
- URL: `{{base_url}}/api/{{api_version}}/matches/{{test_match_id}}`
- 请求体: `{"matchId": {{test_match_id}}}`

### 3. 批量测试

1. 选择集合或文件夹
2. 点击 **"Run"** 按钮
3. 选择要运行的接口
4. 点击 **"Run"** 执行

## ⚠️ 注意事项

1. **先测试后生产** - 建议先在测试环境完整测试，确认无误后再在生产环境测试
2. **环境变量** - 创建资源后，记得更新对应的环境变量（如 `test_match_id`）
3. **请求头** - POST/PUT 请求需要设置 `Content-Type: application/json`
4. **数据清理** - 测试完成后，建议清理测试数据

## 🆘 常见问题

### Q: 环境变量不生效？
A: 确认已选择正确的环境（右上角环境选择器）

### Q: 请求失败？
A: 检查：
1. 服务是否正常运行
2. 环境URL是否正确
3. 网络连接是否正常

### Q: 如何手动更新环境变量？
A: 点击右上角环境名称 → 编辑环境 → 修改变量值 → Save
