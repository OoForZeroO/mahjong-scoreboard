# Postman 环境配置说明

## 当前配置

### 生产环境
- **base_url**: `https://yaohufox.com`
- **说明**: 生产环境通过 Nginx 代理，使用 HTTPS

### 测试环境
- **base_url**: `https://yaohufox.com` （已更新，请根据实际情况修改）
- **说明**: 测试环境地址需要根据实际部署情况配置

## 如何修改测试环境地址

### 方法1：在 Postman 中直接修改

1. 点击 Postman 右上角的环境选择器
2. 点击 **"测试环境"** 右侧的 **"眼睛"图标** 或 **"..."** → **"Edit"**
3. 找到 `base_url` 变量
4. 修改 **"Current Value"** 为实际的测试环境地址
5. 点击 **"Save"** 保存

### 方法2：修改配置文件后重新导入

1. 编辑 `测试环境.postman_environment.json` 文件
2. 修改 `base_url` 的 `value` 字段
3. 在 Postman 中删除旧的环境配置
4. 重新导入更新后的配置文件

## 测试环境地址选项

根据您的实际部署情况，选择以下之一：

### 选项1：测试环境有独立域名
```json
"value": "https://test.yaohufox.com"
```

### 选项2：测试环境使用服务器IP
```json
"value": "http://192.168.1.100:8082"
```
（将 IP 替换为实际服务器IP）

### 选项3：测试环境在同一服务器不同端口
```json
"value": "https://yaohufox.com:8082"
```
或
```json
"value": "http://yaohufox.com:8082"
```

### 选项4：测试环境在本地
```json
"value": "http://localhost:8082"
```
（确保服务正在运行）

## 快速测试

修改配置后，按以下步骤测试：

1. 选择 **"测试环境"**
2. 打开 **"健康检查"** 接口
3. 点击 **"Send"**
4. 如果返回 `Hello World!`，说明配置成功

## 验证配置是否正确

在浏览器或使用 curl 测试：

```bash
# 替换为您的测试环境地址
curl https://test.yaohufox.com/api/test/hello
# 或
curl http://服务器IP:8082/api/test/hello
```

如果浏览器/curl 能正常访问，但 Postman 不能，检查：
1. Postman 环境选择是否正确
2. 环境变量是否已保存
3. 尝试刷新请求或重启 Postman

## 注意事项

1. **HTTPS vs HTTP**: 如果使用 HTTPS，确保证书有效
2. **端口**: 如果使用非标准端口（如8082），确保端口在 URL 中
3. **防火墙**: 如果使用服务器IP，确保防火墙允许访问
4. **网络**: 确保能访问到服务器地址

---

**提示**: 如果不确定测试环境地址，可以先使用生产环境进行测试。
